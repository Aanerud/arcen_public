Arcen Pier is installed

The Pier service is running and listening for Decks. Before it can show this Mac's screen and take keyboard input, macOS needs your approval. Only someone at this Mac can give it.

Approve, once, for each person who will be served

  1. System Settings > Privacy & Security > Screen & System Audio Recording: turn on Arcen Agent Helper.
  2. System Settings > Privacy & Security > Accessibility: turn on Arcen Agent Helper.

macOS may ask for these itself when the helper starts. Choose Allow, or open System Settings to allow it.

The login window

The login window asks separately. The first time a Deck connects before anyone has signed in, someone at this Mac must allow screen capture there.

To remove Arcen Pier

sudo "/Applications/Arcen Pier.app/Contents/Resources/uninstall.sh"
Add --purge to also remove the host identity, configuration, logs and the _arcen service account.
