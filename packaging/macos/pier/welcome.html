Arcen Pier

Arcen Pier lets you use this Mac's desktop from another computer running Arcen Deck: its screens, sound, keyboard, pointer and clipboard, over an encrypted connection (QUIC with TLS 1.3 on UDP port 18444). People sign in with the accounts they already have on this Mac.

What is installed, and why it is more than one app

macOS allows screen capture and typing only inside a signed-in person's session, and only for that person. A remote host must also stay reachable when nobody is signed in. No single program can do both, so Arcen Pier is split, and each part gets only what it needs:

  • Arcen Pier in Applications: the network service. It starts at boot, listens for Decks, holds this Mac's encryption key and checks passwords. It cannot see or control any screen. It runs as a hidden service account, _arcen, never as an administrator or root.
  • Arcen Agent Helper, a background helper in /Library/PrivilegedHelperTools. It runs inside each signed-in person's session as that person, to capture the screen and sound and to type and move the pointer. It has no network port and cannot read the key. At the login window, before anyone has signed in, macOS starts it as root.
  • A sign-in rule (/etc/pam.d/arcen) so a Deck is checked against this Mac's own accounts, and an exception in the macOS firewall when the firewall is on.

Why a separate account: if the network service ever had a flaw, whoever exploited it would get an account that can read one key and use one port, not this Mac. _arcen has no password and no shell, is hidden from the login window, and nobody can sign in as it.

No kernel or system extension and no configuration profile is installed. The full explanation, with what each part can and cannot do: https://github.com/Aanerud/arcen_public/blob/main/docs/security/macos-pier-process-model.md

What macOS will ask you

  • Your administrator password, to install into /Library.
  • The first time only: "Installer would like to administer your computer". That is macOS asking before the installer creates the hidden _arcen service account. No other account or password is changed. If you choose Don't Allow, the install stops and nothing runs.
  • After installing, each person who will be served approves Screen & System Audio Recording and Accessibility for Arcen Agent Helper, once.
  • A notification that background items were added: the network service and the helper above. Both belong to Arcen Pier.
